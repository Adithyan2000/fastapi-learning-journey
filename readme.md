# FastAPI Learning Journey

A hands-on backend project built while learning
Python and FastAPI.

## Tech Stack
- Python
- FastAPI
- SQLAlchemy
- SQLite
- Alembic
- Pydantic
- JWT Authentication

## Features
- User registration and login
- Password hashing with Argon2
- JWT-protected endpoints
- User and Todo CRUD APIs
- One-to-many database relationships
- Authorization and ownership checks
- Database migrations
